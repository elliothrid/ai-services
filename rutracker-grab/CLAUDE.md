# rutracker-grab — CLAUDE.md

Личный инструмент: по списку ссылок rutracker.org чистит заголовок, раскладывает по
папкам общей папки NAS, сохраняет страницу одним файлом (MHTML), кладёт постер
`folder.jpg`, заводит закачку в qBittorrent. **Полная архитектура — в `DESIGN.md`,
читать первым.** Этот файл — только конвенции и «не нарушать».

## Как работать над проектом
- Python 3.12. Общий venv репозитория — корневой `ai-services/.venv` (из
  `rutracker-grab/` это `../.venv`); отдельный venv в проекте не заводим.
  Прогон тестов: `../.venv/Scripts/python.exe -m pytest`.
- Прежде чем трогать разбор заголовка — свериться с `DESIGN.md` §5 (правила) и §15
  (4 канонических тест-кейса). Любое изменение парсера обязано проходить эти кейсы.
- **Детерминизм по умолчанию.** LLM — только на «нечётких» местах (§5.2), за
  интерфейсом `normalize.py`; стартовый провайдер = `none` (правила + интерактив).
- **Ничего не пишем на диск / в qBittorrent, минуя валидаторы-инварианты (§11).**
- Инструмент задуман интерактивным: если правило неоднозначно — спросить
  пользователя, не угадывать молча. **`interactive.py` пока не написан**, поэтому
  неоднозначность = ошибка `ParseAmbiguous`, тема пропускается (§9, §12).

## Ключевые инварианты (не нарушать)
- `leaf` (имя папки) байт-в-байт одинаков в SMB-mkdir и в qBittorrent `save_path`.
- Ровно одна `[год]`-скобка (1900–2100); языковой хвост (` / Eng…`) не просачивается
  в название/режиссёра; имя папки Windows-легально (санитизация до обоих потребителей).
- Постер всегда `folder.jpg` (конвертация через Pillow, альфа на белый фон).
- Страница — `About.mhtml`, запись ТОЛЬКО бинарная (`write_bytes`): `write_text` на
  Windows делает `\r\r\n` из CRLF снапшота → белый экран. Перед снимком прогреть
  ленивые постеры (скролл + ждать `naturalWidth>0`), иначе fastpic/imageban не вшьются.
- Имена папок (`leaf`) всегда содержат `[...]` → НИКОГДА не искать по ним через
  `glob`/`fnmatch`/`Path.glob()`/`rglob`: квадратные скобки трактуются как класс
  символов, поиск молча вернёт пусто. Только `Path.exists()`, `Path.iterdir()`
  (сравнение имён по `==`) или экранирование через `glob.escape()`.
- В батче — своя вкладка на каждую ссылку. Переиспользовать один `page` НЕЛЬЗЯ:
  после таймаута `goto` навигация остаётся висеть, следующий `goto` встаёт за ней
  в очередь, и одна битая ссылка утаскивает все последующие. Контекст — общий.
- Ошибки Playwright (`playwright.sync_api.Error`, включая `TimeoutError`) — НЕ
  `GrabError`. Любой вызов браузера, идущий в батч, оборачивать в `PageLoadError`,
  иначе изоляция §12 не работает. То же про голые `RuntimeError`/`ValueError`.
- Явный `timeout=` на каждом `context.request.get`: дефолт Playwright — 30 с, а
  через SOCKS5 и `dl.php`, и постеры с fastpic отвечают медленнее (§6).

## Правила очистки заголовка (решено, детерминированно)
- Схлопывание языков: брать сегмент до первого ` / ` (в названии и в скобке режиссёра).
- Скобки в названии: убирать «часть/порядок» (`(фильм первый|второй)`, `(часть N)`),
  оставлять «тип» (`(ТВ)`, `(OVA)`); не распознано — фолбэк-вопрос.
- ` - ` между фрагментами названия -> `. ` (автоматически).
- Главная скобка `[год, страна, жанр, tech…]` -> `[год] [tech…]` (tech = от первого
  формат-токена; страны/жанры отбрасываются). Аудио/саб-скобки и хвост Dub/MVO/Sub —
  выбрасываются. Порядок остальных скобок сохраняется.
